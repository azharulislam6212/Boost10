<boost-carousel>

The theme's own carousel, with no Swiper anywhere on the page — neither swiper.js nor swiper.css is loaded. Every control is drawn by base.css from the classes the Swiper-backed sections already use, so what is on screen is the current design running on the new engine. Drag with a mouse, swipe with a finger, tab to a track and use the arrow keys, Home and End.
